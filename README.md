# study-salesforce

Salesforce certification study workspace.

## Marketing Cloud Next Consultant

Interactive 180-question flashcard site based on the Easy, Intermediate, and Advanced practice sets.

- 180 questions total
- Study Mode / Quiz Mode / Performance
- Easy / Intermediate / Advanced filters
- Section filters and keyword search
- Known / Review tracking
- Quiz correct / incorrect tracking
- Browser localStorage keeps study progress on the device
